# Contributing

Bug reports and pull requests are welcome.

1. Fork the repo and create a branch.
2. Run the tests before opening a PR:
   ```
   python tests/make_test_media.py media
   python tests/test_effects_matrix.py media work
   python tests/test_engine.py media work
   ```
3. When reporting a bug, attach the log from `~/.amv_studio/logs/amv_studio.log` (the app's **Support** button bundles it) and your OS / Python version.

Please do not upload copyrighted game footage or music to issues or PRs.
